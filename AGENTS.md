# AGENTS.md

## Regras do projeto

- Leia `DOCS/RegrasDesenvolvimento.md` antes de alterar código, conteúdo, configuração ou documentação.
- Mantenha textos em `src/data/`, lógica de domínio em `src/lib/`, configurações em `src/config/` e apresentação em `src/components/` ou `src/sections/`.
- Use React com function components e hooks, TypeScript strict, Tailwind CSS com configuração CSS-first e oxlint.
- Preserve acessibilidade, responsividade mobile-first, performance e suporte a `prefers-reduced-motion`.
- Atualize `DOCS/Documentacao-Aplicacao.md` quando arquitetura ou comportamento forem alterados.
